# Локальный сигналинг-сервер (опционально)

По умолчанию приложение использует публичный облачный сигналинг PeerJS (`0.peerjs.com`) для установки WebRTC-соединения, после чего данные игры передаются напрямую P2P между игроками.

Если вы хотите полностью автономный сигналинг в своей локальной сети (Wi-Fi) или на своём сервере:

```bash
npx peer --port 9000 --path /bunker
```

Затем в приложении нажмите на иконку настроек (шестерёнка) на главном экране и укажите IP-адрес компьютера с запущенным сервером (например, `192.168.1.50`), порт `9000`, путь `/bunker`.
