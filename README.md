# БУНКЕР // P2P (Windows, Android, iOS, Web)

Кроссплатформенная реализация настольной игры **«Бункер»** с прямым P2P-подключением через **WebRTC DataChannels** (PeerJS).

## Возможности
- **P2P по коду комнаты** — хост хранит состояние партии и отправляет каждому игроку только его скрытые карты (защита от подглядывания).
- **Полные правила игры**: катастрофа, описание и карты угроз/ресурсов бункера, 7 характеристик персонажа, 8 типов спецкарт действий, фазы вскрытия, обсуждение, голосование с переголосованием при ничьей, чат.
- **PWA + Mobile + Desktop**: адаптивный интерфейс для телефонов и ПК.

## Быстрый старт (Web / PWA)
```bash
npm install
npm run dev
```
Откройте `http://localhost:5173/` на ПК или адрес `Network` на телефоне в той же Wi-Fi сети.

## Как играть через интернет (вне локальной сети)
Само P2P-соединение (PeerJS Cloud + STUN) уже работает через интернет, но игрокам из других сетей нужен **публичный HTTPS-адрес**, чтобы открыть приложение:

1. **Быстрый способ (без деплоя) — туннель с вашего ПК:**
   Запустите `npm run dev`, а во втором окне терминала пробросьте порт в интернет (например, через Cloudflare Tunnel или Localtunnel):
   ```bash
   npx localtunnel --port 5173
   ```
   *(или `cloudflared tunnel --url http://localhost:5173` — стабильнее, без экрана подтверждения).*
   Отправьте полученную `https://...` ссылку друзьям — они смогут зайти с любого устройства и подключиться по 5-значному коду комнаты.

2. **Постоянный способ (бесплатно) — GitHub Pages:**
   В репозитории уже добавлен workflow `.github/workflows/deploy.yml`. Загрузите проект на GitHub, включите **Settings -> Pages -> Source: GitHub Actions**, и приложение получит постоянный HTTPS-адрес.

3. **Если не соединяет с мобильного интернета (строгий NAT / 4G):**
   В настройках на главном экране (иконка шестерёнки) можно указать **TURN-сервер** (`turn:...`, логин и пароль — например, бесплатный тариф Metered.ca или собственный `coturn`).

## Сборка под Windows (Electron)
```bash
npm install -D electron electron-builder
npm run build
npx electron .
```

## Сборка под Android и iOS (Capacitor)
```bash
npm install @capacitor/core @capacitor/cli
npm run build
npx cap add android
npx cap add ios
npx cap sync
```
- **Android**: `npx cap open android` (откроется Android Studio для сборки `.apk`/`.aab`).
- **iOS**: `npx cap open ios` (требуется macOS с Xcode или облачный CI вроде GitHub Actions / Codemagic). На iPhone также можно сразу играть через Safari -> «На экран Домой» (PWA).

## Локальный сигналинг-сервер (опционально)
По умолчанию используется публичный сигналинг PeerJS (`0.peerjs.com`). Для полностью автономной игры в локальной сети:
```bash
npx peer --port 9000 --path /bunker
```
И укажите IP сервера в настройках (иконка шестерёнки на главном экране).
